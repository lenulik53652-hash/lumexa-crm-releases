# Lumexa CRM releases

Installers for the Lumexa CRM desktop app. Each version is one GitHub release with three files attached:

- `Lumexa-CRM-<version>-mac-arm64.dmg` — Mac with Apple silicon (M1 or newer). Open the file and drag Lumexa CRM into Applications. On first launch choose "Open Anyway" in System Settings → Privacy & Security if macOS asks.
- `Lumexa-CRM-<version>-mac-x64.dmg` — Mac with an Intel chip (Apple menu → About This Mac says "Intel"). Same steps.
- `Lumexa-CRM-<version>-windows-x64.exe` — Windows 10/11. Run the installer; if Windows shows "unknown publisher", click More info → Run anyway.

The app checks the latest release and offers the download for its own platform and chip.

No data, no source code lives here.
