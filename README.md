# Lumexa CRM releases

Installers for the Lumexa CRM desktop app. Each version is one GitHub release with three files attached:

- `Lumexa-CRM-<version>-mac-arm64.dmg` — Mac (Apple silicon). Open the file and drag Lumexa CRM into Applications. On first launch choose "Open Anyway" in System Settings → Privacy & Security if macOS asks.
- `Lumexa-CRM-<version>-windows-x64.exe` — Windows 10/11. Run the installer; if Windows shows "unknown publisher", click More info → Run anyway.
- `Lumexa-CRM-<version>-linux-x86_64.AppImage` — Linux (any distribution). Mark the file executable (right-click → Properties → Allow executing, or `chmod +x`) and run it.

The app checks the latest release and offers the download for its own platform.

No data, no source code lives here.
